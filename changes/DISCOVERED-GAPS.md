# Discovered gaps and quality improvements

Use this queue when a source inspection, failing test, new requirement or implementation experience reveals a missing or oversized question. **Do not assign a new ID until the proposal is approved for inclusion**; then use the next unused global ID (initially Q1026).

## Resolution procedure

1. Confirm the issue is not already addressed by an existing canonical question.
2. Describe the missing working behavior or regression and why it matters.
3. Choose **ADD**, **REVISE**, **SPLIT**, **MOVE** or **RETIRE**.
4. Update the canonical text, change log, tracker and execution-order overrides.
5. Run the roadmap validator; only then proceed with the impacted implementation task.

Avoid generating filler questions solely to preserve the 1,025 estimate. Real gaps can increase the total; duplicated/redundant tasks can be retired without reusing their IDs.
